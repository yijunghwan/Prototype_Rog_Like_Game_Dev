# 원본 도트 아트 작업 공간

언리얼이 임포트하지 않는 원본 작업 파일 보관소입니다. Aseprite/PSD 파일, 생성 직후 PNG, 레퍼런스, 작업 중인 스프라이트 시트를 둡니다. 게임에서 실제로 참조할 Texture·Sprite·Flipbook은 완성본을 `Content/Game`에 임포트해 만듭니다.

`ArtSource`와 `Content/Game`은 같은 콘텐츠 분류를 유지합니다. 예를 들어 플레이어 원본은 `ArtSource/Characters/Player`, 임포트 에셋은 `Content/Game/Characters/Player`에 둡니다.
