노드의 용도 → 연결 대상 → 입력·출력 → 정리 책임 순서로 확인합니다. 구조체는 설명 아래에서 펼쳐 보거나 Blueprint의 Split Struct Pin / Make 노드로 연결할 수 있습니다.

NavMesh 준비컨트롤러 연결직선·정지·잠금경로 요청CC 이후 재요청

NavMesh 만들기·경로 영역
레벨 설정Nav Mesh Bounds Volume · NavMesh 만들기

NavMesh는 AI가 걸어갈 수 있는 영역과 경로를 계산할 탐색 데이터입니다. 이동 노드가 없는 바닥이나 통로를 자동으로 생성해 주는 것은 아닙니다.

  1. 레벨에 적 Capsule이 실제로 설 수 있는 바닥과 충돌을 준비합니다.
  2. Place Actors(액터 배치)에서 Nav Mesh Bounds Volume을 검색해 배치합니다.
  3. Volume의 위치·크기를 조정하여 이동할 바닥과 경로 영역을 덮습니다.
  4. 레벨 뷰포트에 포커스를 두고 P를 눌러 탐색 영역을 표시합니다. 생성된 이동 가능 면이 시작과 목표를 연결하는지 확인합니다.
  5. 탐색 데이터가 갱신되지 않으면 에디터의 Navigation 빌드/자동 갱신 설정을 확인합니다.

Volume이 바닥을 덮는 것만으로 통행이 보장되지는 않습니다. 바닥 충돌·수직 높이·경사·통로 폭·Nav Agent Radius/Height가 적 Capsule과 맞아야 합니다. 평면 게임의 외형 Sprite가 아니라 실제 월드 바닥을 확인하세요.

정확한 노드 연결·검색 위치
  1. 적 BP에서 Get Controller 노드를 놓습니다. Target은 적 Self입니다.
  2. Return Value를 Cast To ARAIController의 Object에 연결합니다.
  3. As ARAIController 출력에서 선을 끌어 AR AI Move To Actor 또는 AR AI Move To Location을 검색합니다.
  4. Actor 추적이면 Goal에 저장한 TargetActor, 좌표 이동이면 Destination에 월드 Vector를 연결합니다.
  5. 흰 실행선은 판단 이벤트 → Cast → 이동 노드로 이어줍니다. Cast Failed도 확인합니다.

노드 검색이 안 뜨면 빈 그래프의 검색보다 ARAIController 참조에서 선을 끌어 검색하세요. 실제 적의 AI Controller Class와 Auto Possess AI(Placed in World or Spawned) 설정도 확인합니다. 컨트롤러 캐시는 BeginPlay에 준비할 수 있지만 Spawn/빙의 시점에 없으면 이후 유효할 때 다시 얻습니다.

00일반 추적 · 정지 · 이동 잠금
프로젝트 노드Request Basic Move

공통 CC 이동 규칙을 거치는 일반 이동 입력입니다. 지정 위치까지 알아서 이동하는 경로 요청이 아닙니다. 직선 추적은 Event Tick에서 반복 호출합니다.

Target
적의 Movement Control Component.
Direction
대상 위치 − 적 위치. 내부에서 Z=0, 정규화하여 입력합니다.
Scale
기본 1. 이동 입력 크기이며 cm/s 속도 값이 아닙니다.
Return Value
입력 요청 허용 Bool. 실제 도착이나 충돌 없는 이동 성공을 뜻하지 않습니다.

죽음·기절·경직·액션 기본 이동 잠금 등으로 Can Basic Move가 false이면 거절됩니다. 장애물 우회가 필요하면 AR AI Move To 경로를 선택하세요.

프로젝트 노드Can Basic Move / Can Move At All

둘은 동일하지 않습니다. 일반 추적과 액션 이동의 허용 범위를 구분할 때 조회합니다.

Can Basic Move
잠금이 하나도 없어 일반 이동이 허용되는가?
Can Move At All
All Movement 잠금이 없어 액션 이동 등이 가능한가? Basic Movement Only 잠금은 이 값만으로 차단하지 않습니다.
On Movement Lock Changed
Target Actor, Can Basic Move, Can Move At All을 알립니다. 적 판단 루프 재개 조건이나 표시 갱신에 사용합니다.

기절 상태만 지웠다고 모든 잠금이 해제되는 것은 아닙니다. 다른 액션/경직/사망 잠금이 남을 수 있으므로 최종 허용 상태를 조회합니다.

프로젝트 노드Stop Movement Immediately / Stop Movement

공통 Movement Control Component의 Stop Movement Immediately는 CharacterMovement의 현재 움직임을 즉시 정지합니다. 이후 이동 요청을 막는 영구 잠금은 아닙니다.

AI 경로를 사용 중이면 Controller의 Stop Movement로 경로 추적 요청도 중단하세요. 속도만 정지시켰다가 기존 경로가 다시 이동시킬 수 있습니다. 공격 선딜에는 Action Request의 Block Basic Movement While Active와 함께 사용하는 편이 명확합니다.

공통 정지 Target
Movement Control Component.
AI 경로 중단 Target
그 적을 소유하는 AIController.
재개
다음 판단에서 허용 상태를 확인하고 새 이동 요청을 발행합니다. 잠금 해제만으로 취소된 경로가 자동 재개되지는 않습니다.
프로젝트 노드Acquire Movement Lock / Release Movement Lock

콘텐츠가 별도의 이동 제한을 직접 관리할 때 사용합니다. 이미 기절 Definition이나 액션이 소유한 잠금을 중복으로 만들지 마세요.

Acquire: Source Id
이 잠금의 출처 이름. 복수 잠금이 공존할 수 있습니다.
Lock Type
Basic Movement Only=일반 이동 차단, All Movement=모든 이동 차단.
Return Value
Movement Lock Handle. 해제할 때 정확한 핸들을 저장하여 사용합니다.
Release: Handle
자신이 획득한 핸들만 해제. Return Value는 실제 제거 여부.
Release Movement Locks By Source
일치하는 출처 잠금을 제거. 현재 구현에서 Source Id=None은 전체 제거이므로 조심합니다.

전체 잠금 해제로 사망·경직·다른 액션 제한까지 지우지 마세요. 액션이 자동 관리하는 잠금은 액션 종료/취소 경로에 맡깁니다.

01장애물 우회 · AI 경로 이동

직선 입력과 경로 추적은 서로 다른 방식입니다. 같은 적에게 두 경로를 동시에 발행하지 않는 것이 좋습니다. 이 프로젝트의 ARAIController는 이동 잠금이 생기면 진행 중 경로를 중단하고 새 일반 이동 요청을 거절합니다.

프로젝트 노드AR AI Move To Actor / AR AI Move To Location

공유 이동 제한을 확인한 뒤 일반 AI 경로 요청을 시작합니다. 노드의 반환값은 요청 수락 결과이지 도착 이벤트가 아닙니다.

Target
적의 ARAIController 참조. 적 Actor 자체가 아닙니다.
Goal / Destination
추적할 Actor / 목적지 월드 Vector.
Acceptance Radius
도착 허용 반경(cm). -1은 엔진 기본 정책 사용. 충돌 크기와 엔진 도착 정책도 고려되므로 공격 범위는 따로 재확인합니다.
Return Value
Failed / Already At Goal / Request Successful. Request Successful 뒤에도 이후 이동이 중단될 수 있습니다.

경직·기절·선딜 잠금이 생기면 경로가 정지합니다. 해제 후 AI 판단에서 다시 요청합니다. 매 프레임 무조건 새 경로를 발행하기보다 타깃 변경/중단/적절한 갱신 주기를 정하세요.

CC가 끝난 뒤 추적 재요청

ARAIController는 공통 이동 잠금이 생기면 진행 중 경로를 Stop합니다. 상태가 제거됐다고 중단한 경로가 자동 재개되지는 않습니다. AI 판단 루프에서 대상 유효성·Can Basic Move·공격 여부를 확인하고 다시 요청하세요.
