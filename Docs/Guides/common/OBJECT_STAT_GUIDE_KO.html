시간 만료와 반복 스탯 적용 구분

기본값과 최종값은 다릅니다

표의 기본값은 UARStatsComponent의 C++ 초기값입니다. 현재 BP_test_Player나 특정 적 BP의 저장값·실행 중 수치를 조회한 표가 아닙니다. 자식 BP의 Stats Component → AR | Stats | Base → Base Stats, 장비·버프가 값을 바꿀 수 있습니다. 환경 객체는 Stats Component를 추가했을 때만 이 초기값을 가집니다.

표에 없는 Base Stats 항목은 기본 0으로 읽습니다. 최대 체력은 최종 최소 1, 공격 속도는 최종 최소 1이 적용됩니다. 등록 가능한 스탯과 이를 실제로 읽는 기능은 별개입니다.

일반 스탯 최종값 = (Base + Flat 합계) × (1 + Additive Percent 합계 / 100) × Multiplicative 곱 → 스탯별 안전 범위 적용

Flat 50은 수치에 50을 더합니다. 피해 증가율 기본 0에 50%p를 주려면 Flat 50을 사용합니다. Additive Percent 50은 기존 수치의 50%를 더하므로 기본 0에서는 증가하지 않습니다. Multiplicative 2는 2배입니다.

피해 증폭·피격 증가·피해 감소

종류현재 계산예시
주는 피해 증폭전체 + 직접 또는 DOT + 해당 속성을 합산전체20 + 직접30 + 물리10 → ×1.6
받는 피해 증가전체 + 해당 속성을 합산. 방어력 뒤 적용전체50 + 물리20 → ×1.7
피해 감소전체 감소의 잔여 배율 × 해당 속성 감소의 잔여 배율. Independent Damage Reduction 효과도 각각 곱함전체20% 감소 + 물리30% 감소 → ×0.8×0.7=×0.56

일반 피해 흐름: 기본 피해·계수 → 주는 피해 증폭 → 치명타 → 속성 방어·관통 → 받는 피해 증가 → 전체/속성 피해 감소 → 양수 피해 내림(최소 1) → 보호막·체력 배분.

공허(Void)는 방어력·받는 피해 증가·피해 감소·관리형 무적 보장을 우회합니다. 현재 Resolver에서는 공허도 요청 설정에 따라 주는 피해 증폭·치명타·회피가 적용될 수 있습니다. DOT 생성 경로는 회피를 비활성화합니다. bApplyAmplification=false이면 주는 피해 증폭과 받는 피해 증가 모두 생략됩니다. 보호막 우회는 별도의 bIgnoreShield 옵션입니다.

체력 HUD의 실드 표시

기본 자원 HUD는 피통 안에서 빨간 체력 뒤에 회색 실드 구간을 표시하고, 실드가 있으면 숫자를 현재 HP / 최대 HP + 실드로 보여줍니다. 실드 획득·흡수·제거·만료에 따라 갱신하며, 실드가 0이면 추가 숫자가 사라집니다.

표시 기준량은 Max(최대 HP, 현재 HP + 실드)입니다. 합계가 최대 HP를 넘으면 두 구간을 같은 기준으로 줄여 피통 안에 모두 표시합니다. 이것은 UI 비율만 바꾸며 실제 체력·최대 체력·실드 수치를 바꾸지 않습니다. 별도의 실드 최대량 스탯도 추가하지 않습니다.

블루프린트에서 값을 읽고 바꾸기

  1. 플레이어/적 기본값: 자식 BP의 Stats Component에서 Base Stats를 설정합니다. Money는 플레이어만 지원합니다.
  2. 실행 중 숫자 조회: Get Final Stat(Target=플레이어 또는 적 Actor, Stat Type=원하는 항목). 기본값 자체는 Stats Component의 Get Base Stat으로 조회합니다.
  3. 전체 UI 목록: 캐릭터의 Get Stats Component → Get All Final Stat Views. Money는 적·환경 목록에서 제외됩니다.
  4. 버프: 일반 Apply Stat Modifier, 아이템 수명 Apply Item Stat Modifier, 액션 수명 Apply Action Stat Modifier 중 유지 기간에 맞게 선택합니다.
  5. 기본값 실시간 증감: 일반 Apply Stat Modifier의 Operation=Permanent Flat. Set Base Stat은 C++ 내부 함수이며 Blueprint 노드로 공개되지 않습니다.

Flat + Duration=-1은 기록이 남는 무기한 버프입니다. Permanent Flat은 버프 기록 없이 기본값 자체를 변경합니다. 둘 다 자동 세이브를 의미하지 않습니다.

기본 잔액 + Value가 0 미만이면 전체 변경 실패(Success=false), 기존 값 유지. 기존 Flat/퍼센트 버프는 기본 잔액에 포함되지 않아 그 보정분을 영구 잔액처럼 소비할 수 없습니다. 보정이 없는 일반 돈 사용에서는 기본값과 최종값이 같습니다.
계산·수명
바뀐 기본값에 기존 Flat/퍼센트/배율 및 안전 범위가 적용됩니다. 대상 Actor가 유지되는 동안 남으며 시간 만료·출처 제거·아이템 해제·액션 종료로 되돌리지 않습니다. 새 객체로 자동 이전하거나 저장하지 않습니다.
지원 경로
일반 Apply Stat Modifier만 지원. Add Stat Modifier(컴포넌트 보정 등록), 아이템/액션 귀속 노드와 DA Default Stat Modifiers에서는 거절합니다. 아이템·픽업 BP에서도 일반 노드의 Target을 플레이어로 지정하면 사용할 수 있습니다.

돈 지급 예: Interactor → Target, Money / Permanent Flat / Value=100 → Branch(Success). 습득·구매 성공 경로에서 한 번만 실행하고 실패/재진입/중복 지급을 콘텐츠에서 막으세요. 가격 계산·자동 결제·자동 돈 HUD는 별도 구현입니다.

시간 만료와 반복 스탯 적용 구분

스탯 보정의 양수 Duration 만료는 시스템이 처리하므로 제거용 BP 타이머를 따로 만들 필요가 없습니다. 일정 주기로 새 효과를 적용할 때만 예약이 필요합니다. 보유 효과는 Set Item Timer by Event, 한 행동의 효과는 Set Action Timer by Event를 사용하세요. 예약이 정리된다고 일반 보정이나 Permanent Flat 변경까지 되돌아가지는 않습니다.
