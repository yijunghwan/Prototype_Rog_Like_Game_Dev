# 칼리번 → 엑스칼리버 무기 제작 가안

작성일: 2026-09-27

이 문서는 무기 콘텐츠 제작을 시작할 때 AI 또는 개발자에게 전달하기 위한 별도 기획 가안이다. 현재 구현 완료를 뜻하지 않는다. 수치는 테스트 후 조정할 수 있다. 미정 항목은 임의로 확정하지 않는다.

공격력은 AP, 주문력은 SP로 표기한다. 기본 스탯은 모든 진화 단계에서 미정이다.

## 공통 규칙

- 평타와 1스킬의 공격 범위는 사거리 스탯에 비례한다.
- 별도 지정이 없으면 경직 피해와 그로기 피해의 계수는 해당 공격의 피해 계수와 동일하다. 체력 피해·경직·그로기는 각 시스템에서 별도로 계산한다.
- 공격 방향은 기본적으로 마우스 방향이다.
- 여러 적을 한 타격으로 맞혀도 패시브 2·3의 획득 횟수는 타격별 적중 성공 1회로 센다. A1S는 두 타격이므로 두 번 판정한다.
- 물리·불 등 복합 피해도 하나의 타격이면 적중 시 효과는 1회 적용한다. 적중한 대상별 효과 적용과 패시브 스택 획득 횟수는 구분한다.
- 행동은 공통 Action 시스템을 통해 시작·종료·취소한다. 별도 명시한 취소 규칙 외의 항목은 제작 전에 확인한다.
- 진화해도 패시브 1의 처치 스택과 처치 누적 정보를 유지한다.

### 평타 속도와 콤보

- 공격속도 1.0: 1·2타 각각 초당 1회.
- 공격속도 2.0: 1·2타 각각 초당 2회.
- 1·2타 공격 주기: `1 / 공격속도`초.
- 3타 공격 주기: `1.5 / 공격속도`초.
- 선딜레이·후딜레이 배분은 미정이다.
- 콤보 유지 시간은 테스트용 제안으로 **공격 동작 종료 후 1초**를 사용한다. 확정 수치가 아니며 플레이 테스트로 조정한다.
- 다음 평타 시작 시 유지 타이머를 중단하고, 공격 종료 후 다시 센다.
- 콤보가 끊기면 1타부터 시작한다.
- 1스킬 연계 인정 시간은 평타 콤보 유지 시간과 같다.
- 1스킬 시전 시 평타 콤보를 0으로 초기화한다.

## 1차: 봉인된 칼리번

기본 스탯: 미정.

### 패시브 1 — 아발론의 축복

설명: 적 처치로 능력치가 성장하고, 최대 성장 시 받는 피해가 감소한다.

- 적 1명 처치당 1스택. 최대 100스택.
- 스택당 공격력 +1, 주문력 +1, 최대 마나 +1, 최대 스태미나 +0.5.
- 스택당 물리·불·마법 방어력 각각 +0.5.
- 100스택 달성 시 받는 피해 15% 감소.
- 진화 시 스택과 처치 누적 정보를 유지한다. 현재 1킬당 1스택이므로 5킬 단위의 잔여 카운터는 필요하지 않다.

### 패시브 2 — 격렬한 벼락

설명: 1스킬 적중으로 시작해 후속 적중을 이어가 공격 능력을 높인다.

- 1스킬 각 타격의 적중 성공으로 1스택씩 획득한다.
- 이후 다른 공격의 적중 시 효과로도 남은 획득 가능량을 채울 수 있다.
- 1스킬 사용 한 번에 연결된 획득량은 두 경로를 합쳐 최대 5스택.
- 한 타격이 여러 적을 맞혀도 획득은 1회. A1S 두 타격 모두 적중 시 2스택.
- 다음 1스킬 사용 시 미사용 획득 가능량을 이월하지 않는다. 새 사용분으로 교체한다.
- 최대 스택: 1차 10, 2차 20, 3차 30.
- 1스택당 공격속도·이동속도·가하는 전체 피해량 각각 +1%.
- 이 패시브가 제공하는 방어 관통은 10스택 미만 0%, 10~19스택 20%, 20~29스택 30%, 30스택 40%.
- 관통 단계는 합산하지 않는다. 감소 시 현재 스택에 맞는 관통으로 변경한다. 다른 출처의 관통과의 결합은 공통 스탯 규칙을 따른다.
- **실제 체력 피해가 발생한 경우에만 5스택 감소한다. 보호막에만 피해가 들어온 경우에는 감소하지 않는다.**
- 회피·무적으로 체력 피해가 발생하지 않은 경우에도 감소하지 않는다.
- 새 스택 획득 없이 10초 경과 시 10스택 감소. 감소 시점부터 다시 10초를 센다.
- 새 스택 획득 시 마지막 획득 시점부터 10초를 다시 센다.
- 스택은 0 미만으로 내려가지 않는다.

### 평타 — 3단 검격

설명: 좌우 베기 후 강한 돌진 찌르기로 마무리한다.

- 입력: 마우스 좌클릭.
- 코스트: 미정.
- 구르기로 취소 가능. 적중 시 효과 적용.
- 범위: 사거리 스탯 비례. 속도와 콤보는 공통 규칙 적용.

#### A — 왼쪽 베기

- 왼쪽으로 베며 마우스 방향으로 소폭 전진.
- 물리 피해 `AP × 1.0`.
- 경직·그로기 피해 계수 각각 1.0.
- 전진 거리: 소폭. 구체적인 수치는 미정.

#### AA — 오른쪽 베기

- 오른쪽으로 베며 마우스 방향으로 소폭 전진.
- 물리 피해 `AP × 1.0`.
- 경직·그로기 피해 계수 각각 1.0.
- 전진 거리: 소폭. 구체적인 수치는 미정.

#### AAA — 돌진 찌르기

- 준비 동작 후 구르기 정도의 거리로 돌진하며 찌르기.
- 물리 피해 `AP × 1.6`.
- 경직·그로기 피해 계수 각각 1.6.
- 일반 평타 1.5회에 해당하는 시간 소요.
- 경직 발생 시 공격 방향으로 넉백. 넉백 거리는 돌진 거리에 비례.
- 구체적인 돌진·넉백 거리와 속도, 선후딜 배분: 미정.

### 1스킬 — 기사왕의 검술

설명: 직전 평타 단계에 따라 돌진·연격·후퇴·전방위 공격을 사용한다.

- 입력: 미정.
- 코스트: 스태미나 20.
- 기본 쿨타임: 7초.
- 구르기로 취소 불가. 경직으로 취소 가능.
- 모든 타격에 적중 시 효과 적용.
- 범위는 사거리 스탯 비례. 연계 인정 시간은 평타와 동일.
- 시전 후 평타 콤보 0.

#### 1S — 돌진 공격

- 평타 3타와 동일한 선딜 후 마우스 방향으로 돌진.
- 마우스가 최대 거리보다 가까우면 해당 위치까지만 이동.
- 피해 `AP × 2.0`. 물리 속성으로 임시 정리했으며 확인 필요.
- 경직·그로기 피해 계수 각각 2.0.
- 최대 돌진 거리: 구르기의 약 2배. 속도: 구르기보다 빠름.
- 구체적인 거리·속도: 미정.

#### A1S — 빠른 2연격

- 빠른 두 타격. 각 타격에 적중 시 효과 적용.
- 타격당 피해 `AP × 1.5`, 두 타격 합계 `AP × 3.0`.
- 물리 속성으로 임시 정리했으며 확인 필요.
- 타격당 경직·그로기 피해 계수 각각 1.5.
- 타격 간격: 미정.

#### AA1S — 후퇴 검격

- 마우스 방향을 베고 뒤로 순간이동. 2초간 보장 회피 100%.
- 피해 `AP × 0.8`. 물리 속성으로 임시 정리했으며 확인 필요.
- 경직·그로기 피해 계수 각각 0.8.
- 순간이동 거리: 구르기의 약 2배. 구체적인 수치는 미정.

#### AAA1S — 전방위 검격

- 2초 차징 후 검을 바닥에 꽂아 전방위 공격.
- 불 피해 `SP × 2.0 + AP × 3.5`.
- 경직·그로기 피해: 공통 동일 계수 규칙 적용.
- 범위: 사거리 스탯 비례.

### 2스킬 — 서른 개의 횃불과 같은 빛

설명: 마나로 보호막과 경직 저항을 얻고, 원형 빛 공격과 불 적중 버프를 사용한다.

- 입력: 미정. 쿨타임: 20초.
- 공통 취소 규칙 적용. 경직 취소는 핵심 제약이다. 구르기 등 개별 취소 항목은 미정.
- 소비 마나: `min(현재 마나, 최대 마나 × 0.5)`.
- 마나 0에서도 시전 가능.

사용 즉시:

- 3초간 보호막. 보호막량 `소비 마나 × 1.0 + 최대 체력 × 0.05`.
- 3초간 경직 저항을 기존의 2배로 증가. 추후 고정 증가량으로 조정할 수 있다.

사용 시작 1.5초 후:

- 자신 중심 원형 공격. 반경: 구르기 거리 정도.
- 불 피해 `SP × 0.5`.
- 경직·그로기 피해 계수 각각 3.0.
- 경직 발생 시 넉백. 넉백 거리: 원형 반지름 정도.

불 적중 버프:

- 플레이어에게 10초간 부여.
- 이후 적중 시 불 피해 `SP × 0.5 + AP × 0.5` 추가.
- 경직 시 별도 추가 피해를 주는 효과는 아니다.
- 관련 공격으로 경직이 발생한 적에게 2초 기절 적용. 최초 원형 공격만 해당하는지, 버프가 붙은 후속 공격도 해당하는지는 제작 전 확인한다.

## 2차: 칼리번

기본 스탯: 미정. 명시하지 않은 기능은 1차 계승.

### 패시브 1 — 아발론의 축복

이전과 동일. 처치 누적 상태 유지.

### 패시브 2 — 격렬한 벼락

최대 20스택. 10~19스택에서 관통 20%, 20스택에서 관통 30%. 나머지 규칙 동일.

### 패시브 3 — 호수가의 여인의 축복

설명: 마법검을 보유해 추가 적중 효과를 얻고, 회전·투척 공격으로 활용한다.

- 1스킬 타격별 적중 성공 1회당 검 1개 생성. 최대 4개.
- 한 타격으로 여러 적을 맞혀도 1개. A1S 두 타격 모두 적중하면 2개.
- AAA1S의 선딜 완료는 회전 공격 시작 시점이다. 검 생성 조건을 대체하지 않는다.
- **보유 검 1개당 플레이어에게 `SP × 0.25`의 마법 추가 피해 적중 효과를 제공한다.**
- 회전 타격 자체의 기본 피해도 검당 `SP × 0.25`의 마법 피해. 이전 회전 계수 0.5는 폐기.
- 회전 타격에 적중 시 효과 적용.
- 회전 반경·속도는 평타 사거리 비례로 기록. AAA1S 회전 주기와의 결합은 아래 확인 항목 참고.

우클릭 투척:

- 마우스 방향으로 검 1개 투척. 즉시 보유 스택 1 감소.
- 회전 중 투척 가능. 검 수 즉시 감소.
- 투척 쿨타임 1초.
- 마법 피해 `SP × 1.0`. 적중 시 효과 적용.
- 적중 시 마나 5, 스태미나 10 회복.
- 비행 시간 3초. 속도 미정. 사거리는 속도와 비행 시간으로 결정.
- **적 1명 통과 가능. 다음 적을 타격하면 삭제한다. 즉 정상적인 연속 적중의 최대 대상 수는 2명이다.**

자동 투척:

- 검 획득·소비가 5초간 없으면 1회 자동 투척.
- 투척 후 다시 5초를 센다. 새 획득·소비 시 해당 시점부터 재계산.
- 방향은 마우스 방향.

### 1스킬 — 기사왕의 검술

- 최대 저장 2회. 사용당 스태미나 20.
- 7초마다 1회 순차 충전. 최대 충전 시 타이머 정지.
- 최대 충전 상태에서 소비하면 다시 7초를 센다.
- 1S·A1S·AA1S는 기존 동작·피해 유지.
- AAA1S는 검 내려찍기 후 마법검 회전 공격으로 변경.

AAA1S:

- 선딜 완료 후 5초간 현재 보유 마법검 수만큼 회전 공격.
- 별도 변경이 없으므로 선딜 2초와 내려찍기 불 피해 `SP × 2.0 + AP × 3.5`를 계승하는 것으로 정리. 제작 전 확인 가능.
- 검은 1초에 1회전. 각 검은 한 회전마다 같은 적을 최대 1회 타격.
- 회전 기본 피해는 검당 `SP × 0.25`의 마법 피해. 적중 시 효과 적용.
- 회전 중 투척 시 즉시 검 수 감소.

### 2스킬 — 서른 개의 횃불과 같은 빛

- 입력 미정. 쿨타임 20초. 마나 소비·보호막·경직 저항 2배는 이전과 동일.
- 경직으로 취소 가능. 나머지 취소 항목은 미정.

차징:

- 1.5초 전에 손을 떼면 사용 시작부터 총 1.5초가 되는 순간 기존 효과 발동.
- 1.5초 이상, 3초 전에 손을 떼면 즉시 기존 효과 발동.
- 3초 완전 차징 시 강화 내려찍기 발동.

강화 내려찍기:

- 마우스 방향. 불 `SP × 4.0` + 물리 `AP × 4.0`의 복합 피해.
- 하나의 타격으로 적중 효과 1회 적용.
- 공격 범위 미정. 경직·그로기는 공통 동일 계수 규칙 적용.
- 경직 피해가 대상 저항보다 높으면 2초 기절.
- 강화된 불 적중 버프 10초. 강화 계수는 미정이며 일반 계수로 임의 확정하지 않는다.

## 3차: 엑스칼리버

기본 스탯 미정. 명시하지 않은 기능은 2차 계승.

### 패시브

- 아발론의 축복: 이전과 동일.
- 격렬한 벼락: 최대 30스택. 10~19에서 관통 20%, 20~29에서 30%, 30에서 40%.
- 호수가의 여인의 축복: 검 최대 4개 유지. 투척은 적 2명 통과 후 다음 적을 타격하면 삭제. 정상적인 연속 적중의 최대 대상 수는 3명.
- 사용자의 “패시브 3이 30스택”은 앞선 단계 구조에 따라 패시브 2의 최대 30스택으로 해석한 상태다. 실제 의도가 다르면 수정해야 한다.

### 1스킬 — 기사왕의 검술

- 최대 저장 3회. 7초마다 1회 순차 충전. 최대 충전 시 정지.
- 사용당 스태미나 20.
- 모든 연계 공격에 필중 추가.
- 나머지 동작·계수 동일.

### 2스킬 — 서른 개의 횃불과 같은 빛

- 2차 계승. 실제 차징 중 슈퍼아머·강인함 100 획득. 차징 종료 시 해제.
- 차징 중 주변 적을 자신에게 끌어당김.
- 끌어당기는 반경은 기존 원형 공격 반경과 동일한 구르기 거리 정도. 속도 미정.
- 완전 차징 내려찍기에 보호막 제거 추가. 보호막량을 전부 제거하는 의미다.
- 내려찍기 불 `SP × 4.0` + 물리 `AP × 4.0`. 나머지 규칙 동일. 범위 미정.

### 3스킬 — 해방

설명: 세계를 느리게 하고 패시브를 강화한다. 재시전으로 연속 검격을 펼칠 수 있으며 종료 후 반동을 받는다.

- 입력 미정. 코스트 없음. 층당 1회 사용.
- 지속시간: 플레이어 정상 시간 기준 7초.
- 세계 시간 배율 0.4. 플레이어는 평상시 1.0 기준과 동일.
- 플레이어 이동·구르기·공격·차징·쿨타임과 플레이어 측 무기·유물 타이머는 정상 시간으로 보정.
- 세계 이동·투사체·행동은 0.4배. 세계 시간을 따르는 경직·기절은 느려진 만큼 실제 지속시간 증가.
- 플레이어의 CC까지 세계 시간을 따르게 할지는 확인 필요.

지속 중:

- 아발론의 축복 강화로 받는 피해 감소 35% 추가. 별도의 패시브 1 강화는 없음.
- 격렬한 벼락 30스택으로 설정. 공격속도·이동속도 각각 20% 추가 증가.
- 격렬한 벼락의 관통을 40%에서 50%로 강화. 40%와 50%를 더하지 않음.
- 마법검 4개 고정. 투척해도 감소하지 않음. 투척 쿨타임 1초.
- 호수가의 여인의 축복 관련 피해를 공허로 변경.

#### 재시전 — 원탁의 기사들

설명: 12자루의 검으로 연속 베기 후 거대한 검을 내려꽂는다.

- 코스트 없음. 해방 1회당 재시전 1회.
- 시전 중에만 무적·강인함 100·슈퍼아머.
- 마우스 방향으로 12회 베기. 공허 피해, 타격당 `AP × 0.25 + SP × 0.25`.
- 타격 간격: 플레이어 정상 시간 기준 0.2초.
- 마지막 내려찍기: 공허 `AP × 5.0 + SP × 5.0`, 확정 치명타.
- 총 13회 모두 적중 시 효과 적용.
- 경직·그로기 피해는 공통 동일 계수 규칙 적용.
- 마지막 내려찍기는 보호막 관통 및 보호막 제거. 앞선 12타까지 보호막 관통하는지는 미정.
- 범위와 마지막 내려찍기 지연은 미정.
- 재시전 도중에는 해방 7초가 지나도 종료하지 않음.
- 재시전 완료 시 남은 시간과 관계없이 반드시 해방 종료.

해방 종료:

- 감속과 강화 효과 해제. 시전용 무적·강인함·슈퍼아머 해제.
- 정상 시간 기준 7초간 받는 피해 100% 증가.
- 현재 마나 0, 격렬한 벼락 스택 0, 마법검 스택 0.
- 아발론의 축복 처치 누적 상태 유지.

## 제작 전 남은 확인 항목

다음 항목은 기획을 임의로 채우지 않고 남긴다.

- 평타 코스트, 각 입력키, 구체적인 거리·속도·선후딜·범위.
- 콤보 종료 후 1초는 테스트용 제안이며 조정 가능.
- 1S·A1S·AA1S의 물리 속성 확정 여부.
- 2스킬의 경직 시 2초 기절이 최초 원형 공격에만 적용되는지, 불 버프를 받은 후속 공격에도 적용되는지.
- 2차 완전 차징의 강화 불 적중 버프 계수.
- 패시브 2의 획득 가능량은 다음 사용 시 교체하지만, 1스킬이 빗나가도 이전 획득 창을 즉시 교체할지는 확인 필요.
- 최대 스택에서의 적중이 감소 타이머를 갱신하는지. 실제 새 스택 획득만 갱신하는지.
- 일반 보유 마법검의 회전 타격 활성 여부와 빈도. AAA1S 회전은 1초 1회로 정해져 있으므로, 사거리 비례 속도가 선속도인지 회전 주기 변경인지 확인 필요.
- 투척 직후 보유 검이 줄어든 상태에서 추가 적중 피해를 계산할지, 투척 시점의 보유 수를 저장할지.
- 궁극기 중 플레이어 CC 시간 기준, 재시전의 취소 가능 여부와 강제 중단 시 종료 처리.
- 재시전 12타의 보호막 관통 여부, 마지막 내려찍기 범위·지연.

## 구현 전달 시 주의사항

- 진화 시 새 무기 인스턴스로 처치 누적 상태를 이전하는 기능이 필요하다.
- 충전 횟수와 순차 회복, 누르기·떼기 입력 전달, 넉백·끌어당기기, 공격별 확정 치명타, 층별 사용 제한, 플레이어 정상 시간 타이머를 구현해야 한다.
- 현재 공격속도 스탯의 단위가 이 문서의 1.0 기준과 일치하는지 먼저 확인한다. 기존 단위가 다르면 변환 규칙을 마련한다.
- 현재 피해 요청은 단일 속성이므로 복합 피해는 논리적 타격 1회와 속성별 피해 계산을 분리해 적중 효과가 중복 발동하지 않게 한다.
- 경직·그로기 계수를 기존 시스템의 기본 피해·증폭 입력으로 어떻게 변환할지 정한다. 최종 체력 피해를 그대로 경직 피해로 복사한다는 의미는 아니다.
- 추가 적중 피해가 자신을 다시 발동하는 무한 연쇄를 만들지 않도록 발동 출처와 재발동 규칙을 정한다. 마법검의 회전·투척이 보유 검 적중 효과를 받는 것과 무한 재발동은 구분한다.
- 전역 적중 이벤트에 공격 출처·논리적 타격 식별자를 전달해 다른 무기·유물과 섞여도 판정을 구분할 수 있어야 한다.
- 궁극기의 정상 시간 보정은 움직임뿐 아니라 차징·쿨타임·버프·자원 회복·히트박스 수명까지 검토한다. 적 투사체와 플레이어 투사체의 시간 기준도 구분한다.
- 공허 피해와 전체 피해 증가·받는 피해 증가의 상호작용은 기존 계산 규칙을 확인한다. 해방 반동이 공허에도 적용되는지는 별도로 정한다.
- 보호막 제거와 보호막 무시는 별개다. 적중이 무효인 경우까지 보호막을 제거하지 않도록 처리 순서를 정한다.
- 격렬한 벼락의 피격 감소는 체력 피해 기준으로 검증한다. 보호막 전량 흡수 시 감소 없음, 보호막을 뚫고 체력 피해가 발생하면 감소.
