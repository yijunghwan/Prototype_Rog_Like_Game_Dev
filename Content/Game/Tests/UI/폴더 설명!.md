# 테스트 UI

기반 시스템 검증을 위한 임시 Widget을 둡니다. 본편 화면은 `Content/Game/UI`, 임포트 UI 이미지는 `Content/Game/Art/UI`에 둡니다.

## 임시 자원 HUD

`WBP_TestResourceHUD`는 `ARResourceHUDWidget`을 부모로 하는 실제 Widget Blueprint입니다. 체력(빨강), 스태미나(초록), 마나(파랑)의 바와 현재값/최대값을 화면 왼쪽 위에 표시합니다. 이미지 없이 기본 UMG 도형을 사용합니다.

현재값/최대값은 소수점 없이 반올림해 표시합니다. 실제 자원값과 게이지 비율은 실수 정밀도를 유지합니다. 숫자 형식은 부모 C++ `ApplySnapshot`에서 지정합니다.

`AARPlayerController`는 로컬 플레이어의 게임 시작과 Pawn 변경 시 HUD를 자동 생성·연결합니다. `AR | UI`의 `Show Resource HUD`로 끄고 `Resource HUD Class`로 다른 자식 Widget을 지정할 수 있습니다. 화면은 마우스 입력을 가로채지 않습니다.

외형은 언리얼에서 `WBP_TestResourceHUD`를 열어 **Designer**에서 색상·폰트·크기·배치·앵커를 수정합니다. 데이터 연결을 유지하려면 아래 이름과 종류를 유지하세요.

- Progress Bar: `HealthBar`, `StaminaBar`, `ManaBar`
- Text: `HealthValue`, `StaminaValue`, `ManaValue`

Graph에서 별도 바인딩을 만들 필요 없이 부모 C++가 `UI Manager`의 자원 변경 데이터를 받아 갱신합니다. 자원값을 Widget이 직접 변경하지 않습니다. 현재 HUD는 기본 3개 자원만 표시하며 보호막·스킬·인벤토리는 아직 화면에 표시하지 않습니다.

에셋이 없는 새 체크아웃에서 재생성하려면 빌드 후 UnrealEditor-Cmd에 프로젝트와 `-run=ARCreateResourceHUD -unattended -nop4 -NullRHI`를 전달합니다. 도구는 기존 에셋을 덮어쓰지 않습니다.
