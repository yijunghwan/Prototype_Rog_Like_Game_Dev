# Game 콘텐츠 루트

프로젝트가 만드는 로그라이크 게임 콘텐츠의 루트입니다. 플레이어, 적, 맵, 무기, 유물, UI와 테스트 에셋을 이 폴더 아래에 둡니다.

- `Foundation`: 공용 부모 Blueprint·입력·공통 데이터
- `Art`: 언리얼로 임포트한 도트 그래픽·FX
- `Objects`: 플레이어·적·아이템·월드 객체의 Blueprint와 Definition
- `Maps`: 실제 게임용 메인 맵과 조립형 방
- `UI`: 본편 Widget Blueprint
- `Tests`: 테스트 맵·플레이어·게임모드·임시 HUD

언리얼이 실제로 참조하는 임포트 에셋은 이 폴더에 둡니다. Aseprite/PSD와 생성 직후 PNG 같은 원본 작업 파일은 프로젝트 루트의 `ArtSource`에 보관합니다.
